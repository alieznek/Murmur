# 隐私与本地数据

## 原文和图片何时离开电脑

- OCR 在本机处理截图或图片；本项目不会将图片发送给在线平台进行 OCR。
- 选择 Argos 离线翻译时，原文留在本机，运行期间不下载模型。
- 选择在线平台并发送翻译时，所选平台接收该次原文、源/目标语种及必要的模型参数。图片先在本机识别，发送的是用户确认并提交的文本。
- 设置页的主动连接验证发送固定句子 `Hello.` 和鉴权所需信息，不发送聊天输入内容。打开、切换或保存设置不主动调用翻译接口。

项目不提供共享密钥、公共代理、统计遥测或云端历史同步。在线平台对内容和账户数据的处理以该平台的规则为准。准备依赖和模型、打开官方帮助链接等主动操作需要联网，不能将“本地 OCR”理解为应用所有操作都不联网。

## 本地保存内容

默认目录为 `%APPDATA%/Murmur/`，可在“设置 → 常规 → 打开配置目录”查看实际位置：

| 内容 | 位置与用途 |
| --- | --- |
| 设置、字体与外观、平台非敏感参数及凭据引用 | `settings.json` |
| 会话原文、译文、平台名称和可选截图缩略图 | `history.json` |
| 平台密钥 | Windows 系统凭据存储，应用使用 `credential_id` 引用 |
| OCR/离线模型 | 源码版的 `models/`，或完整程序包的资源目录 |

会话文件是本地明文，不是加密保险箱。使用公用电脑或分享用户目录时，先删除相关会话；文件备份可能保留副本。

## 清理与反馈

在历史入口删除不需要的会话。清除密钥时，先在平台设置中删除对应凭据，再退出应用；其他平台的凭据独立保存。手动删除或编辑设置文件会使应用丢失原凭据引用，不能以此代替系统凭据清理。卸载程序默认保留个人设置、会话与系统凭据。

排查问题尽量使用合成文字。截图遮住账号和原文，检查报告后再发送。不要上传 `settings.json`、`history.json`、`.env`、密钥或真实 API 响应正文。自检使用合成图片、固定句子和隔离配置；模拟在线协议结果不代表个人账户已验证。
